Sitio web y portafolio interactivo de **Andy José Cruz García**, Ingeniero de Sistemas y Desarrollador Backend / Datos en Nicaragua con más de 3 años de experiencia en Fintech y Retail.

Inspirado en el diseño minimalista dark/glassmorphic de **Takuya Matsuyama** y **xch4rt.dev**.

---

## 🌟 Características Destacadas

- 🌙 **Modo Oscuro (#202023) y Modo Claro:** Toggle persistente en `localStorage`.
- 🪟 **Glassmorphism Moderno:** Filtros `backdrop-filter: blur(12px)` con estética elegante.
- 📱 **100% Responsivo:** Adaptado a dispositivos móviles, tablets y monitores ultrawide.
- 🔍 **SEO & OpenGraph Optimizado:** Metadatos completos y microdatos estructurados Schema.org JSON-LD para indexación en Google.
- 📋 **Interactivo:** Copiado de correo al portapapeles con feedback visual en 1 clic.
- ⚡ **Zero Dependencies / Ultraligero:** Carga instantánea sin node_modules pesados ni tiempos de compilación.

## 🌐 Publicación en GitHub Pages

Para publicar este portafolio gratis en internet con tu propio subdominio `https://AndyCruz81.github.io/CV-ONLINE/`:

1. Sube los cambios a la rama `main` en GitHub:
   ```bash
   git add .
   git commit -m "feat: portafolio interactivo inicial"
   git push -u origin main
   ```
2. En GitHub ve a **Settings** de tu repositorio `CV-ONLINE`.
3. Entra a **Pages** (en el menú lateral izquierdo).
4. En **Branch**, selecciona `main` y la carpeta `/(root)`.
5. Haz clic en **Save**. ¡En 1 minuto tu portafolio estará público en todo el mundo!
